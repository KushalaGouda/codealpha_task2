# Banking System in C

This is a mini project for CodeAlpha internship.

### Features:
- Deposit
- Withdraw
- Balance Enquiry
- Exit

### Implementation:
- Written in C
- Uses functions, structures, and file handling
- Stores account data in `account.dat`

### How to run:
1. Compile: `gcc bank.c -o bank.exe`
2. Run: `./bank.exe`
